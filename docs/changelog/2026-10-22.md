# 2026-10-22

Shipped application logs from the Lightsail instance to CloudWatch Logs.

- Extended the `dcpass-lightsail` IAM policy so that user can write to the `/dcpass/app` log group. Lightsail has no instance role; the CloudWatch agent uses the existing access keys in on-premises mode.
- The agent reads `/var/log/dcpass/app.log` (systemd `StandardOutput`/`StandardError`) and joins stack traces on the Spring timestamp. Journald was dropped: it stored one event per line and attached the full journal record to each event. `SPRING_OUTPUT_ANSI_ENABLED=never` keeps those lines plain text.
- Tomcat access logs go to `/var/log/dcpass/access*.log` and the `{hostname}-access` stream, including the client address and `X-Forwarded-For`. The pattern is set with a quoted `Environment=` line so systemd does not split it on spaces or strip `%`.
